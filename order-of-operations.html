Order of operations explained

Write 2 + 3 x 4 on paper and two people can get two different answers. One gets 20 by adding first. The other gets 14 by multiplying first. The order of operations is the agreed rule that settles this. Everyone who follows it gets the same answer.

The order

  1. Brackets, working from the inside out.
  2. Exponents (powers), such as 3 to the power 2, written 3²: that is 3 x 3 = 9.
  3. Multiplication and division, working from left to right.
  4. Addition and subtraction, working from left to right.

A common way to remember this is the word BEDMAS, or PEMDAS. Multiplication and division are equals, and so are addition and subtraction. Neither pair has a fixed winner. You simply go left to right within each pair.

Example 1: multiplication before addition

Take 2 + 3 x 4. Multiply first: 3 x 4 = 12. Then add: 2 + 12 = 14. So 2 + 3 x 4 = 14.

Adding first would give (2 + 3) x 4 = 20, which is a different sum. The brackets in that version show the change of order, so they are needed.

Example 2: brackets first

Take (2 + 3) x 4. The brackets come first: 2 + 3 = 5. Then multiply: 5 x 4 = 20.

Example 3: left to right

Take 12 / 3 x 2. Multiplication and division share a level, so work left to right. First divide: 12 / 3 = 4. Then multiply: 4 x 2 = 8. Multiplying first would give 12 / 6 = 2, which is the wrong order here.

The same rule applies to 8 - 4 / 2. Divide first: 4 / 2 = 2. Then subtract: 8 - 2 = 6.

Example 4: powers before multiplication

Take 2 x 3². The power comes first: 3² = 9. Then multiply: 2 x 9 = 18. Compare (2 x 3)², where the brackets come first: 2 x 3 = 6, then 6² = 36. The brackets change the answer, so read them with care.

Example 5: a longer expression

Take 20 / (4 + 1) + 2 x 3 - 1.

  1. Brackets: 4 + 1 = 5, so the expression is 20 / 5 + 2 x 3 - 1.
  2. Divide and multiply, left to right: 20 / 5 = 4, then 2 x 3 = 6. The expression is now 4 + 6 - 1.
  3. Add and subtract, left to right: 4 + 6 = 10, then 10 - 1 = 9.

The answer is 9.

Why the rule exists

Multiplication is a short way of adding the same number many times. So 2 + 3 x 4 means 2 plus three groups of 4, which is 14. Brackets let you choose a different grouping when you need one. Without a shared order, the same written line could mean two things, and that would make recipes, receipts and formulas hard to trust.

Quick check

  1. What is 5 + 2 x 3? (Answer: 11)
  2. What is (5 + 2) x 3? (Answer: 21)
  3. What is 10 - 6 / 2? (Answer: 7)
  4. What is 3 + 2²? (Answer: 7)
  5. What is 18 / 3 x 2? (Answer: 12)

Work each one on paper before checking the answer. If you get one wrong, look at which step came first and why.
