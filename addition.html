Binary addition by hand

If you can add in decimal on paper, you can add in binary. The method is the same: work from the right, add each column, and carry when the column is too big. The only difference is that a column can hold just 0 or 1, so you carry as soon as the total reaches 2.

The four basic sums

SumResultCarry
0 + 000
0 + 110
1 + 010
1 + 101

The last row is the one to remember: 1 + 1 is 2, and 2 in binary is 10, so you write 0 and carry 1 to the next column. If a carry arrives, add it as a third number: 1 + 1 + 1 is 3, which is binary 11, so you write 1 and carry 1.

Example 1: 0101 + 0011

  0101   (5)
+ 0011   (3)
------
  1000   (8)

Right column: 1 + 1 = 0, carry 1. Next: 0 + 1 + carry 1 = 0, carry 1. Next: 1 + 0 + carry 1 = 0, carry 1. Left column: 0 + 0 + carry 1 = 1. The answer is 1000, which is 8.

Example 2: 1011 + 0110

 1011   (11)
+0110   (6)
-------
10001   (17)

Right column: 1 + 0 = 1. Next: 1 + 1 = 0, carry 1. Next: 0 + 1 + carry 1 = 0, carry 1. Next: 1 + 0 + carry 1 = 0, carry 1. The carry has nowhere to go, so it becomes a new leftmost digit: 10001, which is 17.

Example 3: a chain of carries

  1111   (15)
+ 0001   (1)
------
 10000   (16)

The right column makes a carry, and every column after it makes another one, like 999 + 1 in decimal. The result is 10000, which is 16.
