ASCII table

ASCII gives each common character a number from 0 to 127. Printable characters run from 32 (space) to 126 (tilde). Each number can be written in decimal, in hexadecimal, and in binary. This table covers those 95 printable characters.

How to read a row

Take the letter A. Its decimal code is 65. In hex, 65 is 4 times 16 plus 1, so it is 41. In binary, 65 is 64 + 1, so it is 01000001. The binary and hex pages explain how each conversion works.

Patterns to notice

The uppercase letters A to Z run from 65 to 90, and the lowercase letters a to z run from 97 to 122. Lowercase is always 32 more than uppercase. In binary, that is the only difference: the bit worth 32 is set for lowercase letters. The digits 0 to 9 run from 48 to 57.
