Number patterns and sequences: finding the next term

A sequence is a list of numbers that follows a rule. Each number in the list is called a term. Finding the next term means working out the rule from the numbers you already have, then applying it once more. This page covers the two most common kinds of rule, and how to check your answer.

Step 1: look at the differences

Start by subtracting each term from the one after it. Take the sequence 3, 7, 11, 15, ...

Difference+4+4+4+4

The differences are all 4, so the rule is "add 4 each time". The next term is 15 + 4 = 19.

Step 2: if the differences are not equal, try ratios

Sometimes each term is found by multiplying the one before by the same number. Take 2, 6, 18, 54, ...

Term261854?
Multiply by×3×3×3×3

The rule is "multiply by 3 each time". The next term is 54 × 3 = 162. A sequence built like this is called geometric. A sequence built by adding the same amount each time is called arithmetic.

Step 3: look at the differences of the differences

Some sequences have neither a constant difference nor a constant ratio. Take 1, 3, 6, 10, 15, ...

Term1361015?
Difference+2+3+4+5+6

The differences rise by 1 each time, so the next difference is 6. The next term is 15 + 6 = 21. These numbers are called triangular numbers, because they count the dots in triangles of dots with 1, 2, 3, 4 and 5 rows.

Other patterns to know

  • Square numbers: 1, 4, 9, 16, 25, ... Each term is a number multiplied by itself: 1×1, 2×2, 3×3, and so on. The next term after 16 is 25.
  • Fibonacci-style: 1, 1, 2, 3, 5, 8, ... Each term is the sum of the two before it: 3 + 5 = 8. The next term after 8 is 13.
  • Alternating: 10, 7, 10, 7, ... The terms go back and forth between two values, so the next term is 10.

Writing a rule for any term

A rule for an arithmetic sequence can name any term without listing the ones before it. Call the position of a term n, so the first term has n = 1, the second has n = 2, and so on. For the sequence 3, 7, 11, 15, ..., start with the first term and add the common difference for each step after the first:

term = 3 + 4 × (n − 1)

This simplifies to 4n − 1. Check it: when n = 2, 4 × 2 − 1 = 7, which is the second term. To find the 10th term, set n = 10: 4 × 10 − 1 = 39.

A rule that works for the first few terms can still be wrong later. Test it on a term you already know, then use it only to find terms beyond the list.

Worked example

Find the next two terms of 5, 9, 15, 23, ...

  1. Differences: 9 − 5 = 4, 15 − 9 = 6, 23 − 15 = 8.
  2. The differences go up by 2 each time, so the next difference is 10.
  3. Next term: 23 + 10 = 33.
  4. The difference after that is 12, so the term after 33 is 33 + 12 = 45.

The next two terms are 33 and 45.

Check yourself

  1. What is the next term of 4, 8, 12, 16, ...?
  2. What is the next term of 2, 4, 8, 16, ...?
  3. What is the next term of 1, 4, 9, 16, 25, ...?

Answers: 20 (add 4 each time); 32 (multiply by 2 each time); 36 (the next square is 6 × 6).
