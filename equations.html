Solving simple equations

An equation says that two expressions have the same value, for example x + 5 = 12. The letter x stands for a number we do not know yet. Solving the equation means finding the value of x that makes the statement true.

The balance idea

Think of an equation as a set of scales. Both sides must weigh the same. You may do any operation to one side, but only if you do the same thing to the other side. Keeping the scales level is the whole method.

One-step equations

A one-step equation needs one operation undone. Undo it by doing the opposite operation to both sides.

  • x + 5 = 12. The 5 is added, so subtract 5 from both sides: x = 12 - 5, so x = 7.
  • x - 4 = 9. The 4 is taken away, so add 4 to both sides: x = 9 + 4, so x = 13.
  • 3x = 18. The x is multiplied by 3, so divide both sides by 3: x = 18 / 3, so x = 6.
  • x / 4 = 5. The x is divided by 4, so multiply both sides by 4: x = 5 x 4, so x = 20.

Two-step equations

A two-step equation has two operations. Undo them in the reverse of the order you would use to build the expression, which usually means undoing the addition or subtraction first and then the multiplication or division.

2x + 3 = 11. First take 3 from both sides: 2x = 8. Then divide both sides by 2: x = 4.

5x - 7 = 18. First add 7 to both sides: 5x = 25. Then divide both sides by 5: x = 5.

Checking by substitution

Put your answer back into the original equation in place of x. If both sides give the same number, the answer is right. This catches most arithmetic slips.

2x + 3 = 11      with x = 4
2 x 4 + 3 = 8 + 3 = 11      both sides match, so x = 4 is correct

Check 5x - 7 = 18 with x = 5: 5 x 5 - 7 = 25 - 7 = 18. Both sides match.

Quick check

Solve each equation, then check your answer by substitution.

  1. x + 9 = 15
  2. 4x = 28
  3. 2x - 6 = 10

Answers: 1) x = 6, because 6 + 9 = 15. 2) x = 7, because 4 x 7 = 28. 3) x = 8, because 2 x 8 - 6 = 10.

Remember

Whatever you do to one side of an equation, do to the other side too. Undo operations with their opposites: add undoes subtract, multiply undoes divide. Always check the answer in the original equation.
