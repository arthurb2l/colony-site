Circles: circumference and area

A circle is every point that is the same distance from a fixed centre point. Two measures describe a circle: the circumference, which is the distance around its edge, and the area, which is the space inside it. This page explains both, using the number pi.

Radius and diameter

The radius (r) is the distance from the centre to the edge. The diameter (d) is the distance straight across the circle through the centre. The diameter is always twice the radius, so d = 2 x r, and r = d / 2.

Pi

If you measure the distance around any circle and divide it by its diameter, you always get the same number, a little more than 3. That number is pi, written as the Greek letter pi. It cannot be written exactly as a decimal, so for everyday work we use 3.14 as an approximation.

The two formulas

  • Circumference: C = 2 x pi x r (or C = pi x d)
  • Area: A = pi x r x r

The circumference is a length, so its unit is the same as the radius, such as centimetres. The area is measured in square units, such as square centimetres, because the radius is multiplied by itself.

Worked example 1: radius 5

Use pi = 3.14 and r = 5.

C = 2 x 3.14 x 5 = 31.4
A = 3.14 x 5 x 5 = 3.14 x 25 = 78.5

The circumference is 31.4 and the area is 78.5.

Worked example 2: diameter 8

Start with the diameter, so first find the radius: r = 8 / 2 = 4.

C = 2 x 3.14 x 4 = 25.12
A = 3.14 x 4 x 4 = 3.14 x 16 = 50.24

Check: the circumference should be a little more than three times the diameter. Three times 8 is 24, and 25.12 is just above that.

Why area grows faster than the radius

Doubling the radius doubles the circumference, because C depends on r by itself. The area depends on r multiplied by itself, so doubling the radius multiplies the area by four. In the examples above, a radius of 5 gives an area of 78.5. A radius of 10 gives an area of 314, which is four times as large.

Quick check

  1. Find the circumference when the radius is 3 (use pi = 3.14).
  2. Find the area when the radius is 3 (use pi = 3.14).
  3. A circle has a diameter of 10. What is its radius?
  4. Find the area when the radius is 10 (use pi = 3.14).
Answers
  1. 18.84 (2 x 3.14 x 3 = 18.84).
  2. 28.26 (3.14 x 3 x 3 = 3.14 x 9 = 28.26).
  3. 5 (10 / 2 = 5).
  4. 314 (3.14 x 10 x 10 = 314). This is four times the area for radius 5.
