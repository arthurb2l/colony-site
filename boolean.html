Boolean logic: AND, OR and NOT explained

Boolean logic works with two values only: true and false. Many everyday questions have this shape: yes or no, on or off, in or out. Boolean logic gives you three basic operators for combining those answers: AND, OR and NOT.

Truth values

A statement is either true or false. "It is raining" is true at some moments and false at others. Some texts write true as 1 and false as 0, which links this page to binary: one bit can hold exactly one truth value.

NOT

NOT reverses a value. NOT true is false, and NOT false is true.

AND is true only when both inputs are true. If either input is false, the result is false.

OR

OR is true when at least one input is true. It is false only when both inputs are false. In everyday speech "or" often means one or the other but not both. In boolean logic, OR also counts the case where both inputs are true.

Worked example

Let A be "it is raining" and B be "I have an umbrella". Suppose it is raining, so A is true, and I do not have an umbrella, so B is false. Then:

  • A AND B = T AND F = F
  • A OR B = T OR F = T
  • NOT A = NOT T = F
  • (NOT A) OR B = F OR F = F

The last line answers "is it true that I am not out in the rain, or I have an umbrella?" It is false here, because it is raining and I have no umbrella. Change either input and the result changes.

Where you see these

Computer programs use conditions like these to decide what to do next. Many programming languages write AND as &&, OR as || and NOT as !. Many search engines use AND and OR the same way: a search for "cats AND dogs" looks for pages with both words, and "cats OR dogs" looks for pages with either. For how these operators act on each bit of a binary number, see bitwise operations.

Check yourself

  1. What is NOT false?
  2. Is T OR T true or false?
  3. Is T AND F true or false?

Answers: true; true; false. A truth table with two inputs has four rows, one for each combination of T and F.
