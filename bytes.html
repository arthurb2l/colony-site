Bits, bytes and kilobytes

A computer stores everything as binary digits, or bits. One bit is a single 0 or 1. Bits are too small to count with by hand, so they are grouped.

Bits and bytes

Eight bits make one byte. A byte can hold 2 × 2 × 2 × 2 × 2 × 2 × 2 × 2 = 256 different patterns, from 00000000 (zero) to 11111111 (255). A file size of 100 bytes therefore means 100 groups of eight bits, not 100 bits.

Kilobytes: two common meanings

The prefix "kilo" means a thousand, so a kilobyte (KB) is often taken to be 1,000 bytes. Computer memory was usually counted in powers of two, where 210 = 1,024 is close to a thousand. Because of this, a kibibyte (KiB) is defined as exactly 1,024 bytes.

Why a file can look different in two places

Suppose a file is 1,024 bytes long. A tool that uses powers of two reports it as 1 KB (really 1 KiB). A tool that uses thousands reports it as 1.02 KB. Both numbers are correct under their own definition. When you compare sizes, check which unit the tool uses.

Quick check

How many bytes is 2 KiB? (Answer: 2 × 1,024 = 2,048.) How many bits is that? (Answer: 2,048 × 8 = 16,384.)
